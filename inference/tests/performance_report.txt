The TensorRT number is not a fully equivalent application-level measurement.
The PyTorch benchmark uses Ultralytics prediction, including image preprocessing
and result postprocessing. trtexec measures the exported neural network and its
host/device transfers, but does not run the application drawing, confidence
filtering, event storage, GNSS, or camera loop. These results therefore indicate
network execution potential, not final real-camera system FPS.
