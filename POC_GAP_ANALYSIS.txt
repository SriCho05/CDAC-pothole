7. CONSOLIDATED BACKLOG (priority ordered)
=======================================================================

P0 - Required for Phase 1 client vetting
  1. Live sensor fusion loop: GNSS read -> detection ROI ->
     payload -> transmit. (gnss.py + schema.py exist, need the
     orchestrator that wires them during inference.)
  2. Outbound API bridge to client staging server: HTTP POST of
     the POC payload, with retry/backoff and auth headers.
  3. Vehicle/camera rig validation: run camera.py against the
     mounted EO camera on the pilot vehicle, confirm live capture
     and detection latency end to end.
  4. Sensor timestamp source: replace file mtime with hardware
     clock (PTP/NTP/chrony) for ground-truth timestamp_unix_us.

P1 - Required for Phase 2 finalization
  5. Thermal (LWIR) capture + RGB/thermal bbox alignment so
     bbox_thermal_xywh is populated instead of None.
  6. Depth/ToF integration: cross-reference detection ROI with
     depth frame to derive estimated_depth_cm / area_sqcm.
  7. Client-feedback retraining run: export reviewed dataset ->
     train_pipeline --tensorrt --int8 --calib-set with the
     client-approved false-positive tuning.
  8. Thermal hardening: pin power mode (nvpmodel), lock clocks,
     run hours-long soak test, log temp/clock/throttle reasons.
  9. Secure data handoff: TLS client certs / signed payloads,
     schema versioning and contract test against client spec.

P2 - Dataset scale and quality
 10. Dataset partitioning: deterministic train/val/test split
     script (80/10/10) with stratification by class and route.
 11. Dataset cleaning: duplicate/corrupt frame detection, blur and
     exposure filters, class balance report.
 12. Scale collection: 150-200 routes, 25k-50k labeled frames,
     2k-3k clean calibration frames.
 13. Multi-modal collection rig: parallel RGB + LWIR + Depth +
     GNSS/IMU capture with us-level sync.

P3 - Performance and operations
 14. Pipeline FPS: raise ~13 FPS toward model speed (~100 FPS).
     Async preprocessing thread, skip JPEG when no subscriber,
     batch SQLite writes, pinned host memory + dedicated stream.
 15. GPU memory lifecycle: explicit buffer free + context pop on
     shutdown to avoid OOM on restart.
 16. Unify annotation app onto port 8000 (remove separate 8765
     process / iframe).
 17. Dynamic video source: /api/video/set-source + file upload
     instead of hardcoded demo.mp4.
 18. Wire gnss.py into app.py so pothole events carry real
     lat/lng instead of 0.0, and the GIS map populates.

8. WHAT IS ALREADY WORKING TODAY (verified)
=======================================================================

- INT8 TensorRT inference, 10 anomaly classes, ~102 FPS pure
- Unified FastAPI dashboard: live feed, GIS map, saved events with
  clickable /uploads snapshots, clear-all, stop/start feed

- Annotation workspace: canvas UI, YOLO/JSON/COCO export, auto-save
  on navigation, 70 demo frames pre-annotated (215 detections)
- Retrain + INT8 engine build pipeline wired to a Train tab

- Payload format exactly matches the POC "Expected Output" spec
  (except bbox_thermal_xywh, which is null by design)
- 2,500-image INT8 calibration set
- Full documentation set, all pushed to GitHub main
