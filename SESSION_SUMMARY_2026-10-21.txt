3.1 app.py refactor (in progress - ONE KNOWN BREAKAGE)
  a) TRTInference
     - Pinned (page-locked) host buffers for input/output
       -> ~2x faster H2D/D2H
     - close(): frees device buffers and pops the CUDA context so a restart
       does not hit "Cuda Runtime (out of memory)"
     - preprocess() / infer_tensor() split out of infer_detections() so the
       decode+preprocess stage can run on its own thread
  b) InferenceLoop converted to a THREE-THREAD pipeline
     - producer : video decode + CPU preprocess -> pre_queue (maxsize 3)
     - inference: TensorRT + BoxTracker + drawing + JPEG encode
     - db worker: batches pothole events into SQLite (25 rows or 0.5 s)
     - JPEG is encoded ONLY while at least one subscriber is connected
     - add_subscriber() / remove_subscriber() / subscriber_count() /
       latest_frame() added for the new feed model
  c) shutdown_inference() + atexit.register(shutdown_inference) added
  d) KNOWN BREAKAGE (must fix first): the /video-feed route at
     inference/app.py:567 still calls the REMOVED method
     `inf.read_frame()` and polls `inf._stop`. It raises AttributeError
     on first request. The route must be rewritten to use
     add_subscriber() / remove_subscriber() / latest_frame().
     The /api/feed/stop and /api/feed/start routes also assume the old
     single-thread model and need to be reworked to restart/stop the
     three threads.
  e) FastAPI shutdown event (app.on_event("shutdown") -> shutdown_inference)
     is NOT yet added - only the atexit hook exists.

3.2 train_pipeline.py: prepare_yolo_dataset()

      --annotations inference/annotations --model inference/best.pt \

      --engine inference/best_int8.engine

  # Baseline benchmark
  .venv/bin/python inference/benchmark_model.py --engine inference/best_int8.engine
